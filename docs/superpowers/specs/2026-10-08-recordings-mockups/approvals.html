How it behaves
  • Batches group the changes found by one rescan or reindex, such as "you asked Claude to tag 40 recordings". Each shows what changed and the jobs it would start, with Claude jobs in blue so they stand out.
  • Run without Claude runs only the Spark jobs. The Claude notes are left out, and you can still generate them later from the recording.
  • Dismiss runs nothing and keeps the edits. The recordings show their missing outputs with a Process button, so nothing is lost.
  • Private recordings never list Claude jobs. They show as "Claude skipped: private".
  • The same is available from the command line: recordings pending list | run | run --no-claude | dismiss, with --json.
