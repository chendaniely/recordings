Several sets of notes on one recording

What happens with several prompts and models
  1. Every pairing of note type and model produces its own set of notes. Three note types (Lecture, Course notes, Action items) run on two models (Spark, Claude) gives six sets of notes, all kept.
  2. Regenerating never overwrites. The new version appears on top, and earlier ones move to History, so you can always see what the old prompt produced.
  3. Stale (orange dot) means the notes were written with an older version of the prompt or model than the one you have now. They stay readable until you regenerate.
  4. A note type you've added but not generated yet shows a Generate button in place of the notes.

Two ways to lay that out. Click the one you prefer.

A

A tab per note type

Each note type gets its own tab next to Transcript, with a model switch and a History menu inside. Quickest with two to four note types. With many, the extra tabs go into a "More" menu.

A single Notes tab beside Transcript. A list down the left shows every set of notes, grouped by note type, with models and older versions nested inside. Fits any number of note types and shows everything at a glance.
