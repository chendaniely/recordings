Tagging, version 3

All of this works. Select rows the way you would in Finder: click for one row, ⌘/Ctrl-click to add or remove a row, Shift-click for a range. The checkboxes still work too. Drag the selection onto a tag. Tick rows and press T to type a tag; Enter adds it and the box stays open so you can add more. Dropping onto + New tag… opens the same box for typing a new name, and / makes folders (for example school/course-101/labs). Everything applies immediately, with Undo.
