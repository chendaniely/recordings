# COURSE 101 Week 4: Viewing rendered reports in Codespaces

TL;DR

Reports render to port 8000. Make the port public, preview in the editor, and restart the server from a new terminal if the port is missing.

Key points

  • Port 8000 ("Rendered reports") starts each time VS Code connects.
  • Public visibility exposes workspace files: practice data only.
  • "Address already in use" means the server is already running.

Questions asked

  • Why is there no globe icon on port 8000? (It is private until changed.)
